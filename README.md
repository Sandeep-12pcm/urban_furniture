# urban_furniture
Odoo hackathon

## Accounting system module

This repository now includes a lightweight accounting engine in
`accounting_system.py` that supports:

- Master data entry: Contacts, Products, Chart of Accounts, Budget, and Journals
- Sales, purchase, and payment recording using configured master data
- Automated reporting:
  - Balance Sheet
  - Profit & Loss (P&L)
  - Budget Report
  - Stock Report
